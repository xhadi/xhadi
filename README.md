### 📌 Featured Project

#### [KFU Scheduler](https://github.com/xhadi/kfu-scheduler)

An intelligent, full-stack schedule generation platform for King Faisal University students. It computes every conflict-free timetable combination from official course offerings using a recursive backtracking algorithm, backed by an automated scraper pipeline that keeps course data fresh.

<p>
  <img src="https://img.shields.io/badge/React_19-61DAFB?style=flat-square&logo=react&logoColor=black" alt="React 19"/>
  <img src="https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white" alt="FastAPI"/>
  <img src="https://img.shields.io/badge/Supabase-3FCF8E?style=flat-square&logo=supabase&logoColor=white" alt="Supabase"/>
  <img src="https://img.shields.io/badge/GitHub_Actions-2088FF?style=flat-square&logo=githubactions&logoColor=white" alt="GitHub Actions"/>
</p>

**Highlights**
- 🧩 Combinatorial schedule engine using recursive backtracking with an MRV heuristic
- 🔄 Dual-strategy scraper (static HTML + dynamic API fallback) refreshing course data every 6 hours via GitHub Actions
- ⚡ Instant client-side filtering by day-off, instructor, and CRN
- 🌙 Responsive UI with dark mode and full Arabic RTL support

🔗 [Live App](https://kfu-scheduler.web.app) &nbsp;|&nbsp; [Repository](https://github.com/xhadi/kfu-scheduler)

<br>

#### [Phishing Detection Agent](https://github.com/xhadi/phishing-detection-agent)

A hybrid ML security tool that classifies email and SMS messages as safe or phishing, combining semantic text embeddings with structural feature engineering. It flags low-confidence cases for human review and highlights exactly which words triggered the detection.

<p>
  <img src="https://img.shields.io/badge/XGBoost-EB0028?style=flat-square&logo=xgboost&logoColor=white" alt="XGBoost"/>
  <img src="https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white" alt="scikit-learn"/>
  <img src="https://img.shields.io/badge/NLP-Sentence--Transformers-4B8BBE?style=flat-square" alt="NLP"/>
  <img src="https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white" alt="Streamlit"/>
</p>

**Highlights**
- 🧠 Hybrid XGBoost engine fusing semantic text embeddings (`all-MiniLM-L6-v2`) with structural signals like URLs, message length, and urgency vocabulary
- 🎯 4-class threat matrix distinguishing safe vs. phishing across both email and SMS channels
- 🧑‍⚖️ Human-in-the-loop review: low-confidence predictions are automatically flagged for manual analyst check
- 🔍 Explainable AI that highlights the exact words driving each threat classification

🔗 [Repository](https://github.com/xhadi/phishing-detection-agent) *(run locally with `streamlit run app.py`)*
